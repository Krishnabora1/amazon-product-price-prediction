# Dataset

Place the challenge dataset files in this directory:

```text
data/
├── train.csv
└── test.csv
```

The raw CSV files are excluded from Git using `.gitignore` because they may be large.

Expected training fields include:

- `sample_id`
- `catalog_content`
- `image_link`
- `price`

Download the dataset from the permitted Amazon ML Challenge source and do not redistribute it if the dataset terms prohibit redistribution.
